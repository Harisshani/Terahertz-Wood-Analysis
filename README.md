# Terahertz-Based Wood Species Analysis

## Project Overview
This project focuses on the analysis and classification of different wood species using Terahertz (THz) spectroscopy and machine learning techniques.

The project explores Terahertz data processing and analysis to identify patterns and differences among various wood species.

## Internship
This project was carried out as part of an internship at **CSIR-CEERI**.

## Objectives
- Analyze Terahertz spectroscopy data.
- Study different wood species using Terahertz measurements.
- Process and explore experimental datasets.
- Investigate machine learning approaches for wood species analysis.

## Technologies Used
- Python
- Jupyter Notebook
- Machine Learning
- Data Analysis
- Terahertz Spectroscopy

## Project Notebooks
- `Diverse_XR.ipynb`
- `Each_species_diverse.ipynb`
- `Each_species_tropical.ipynb`
- `tropical_XR.ipynb`

## Methodology
1. Terahertz data collection and preparation.
2. Data preprocessing and analysis.
3. Analysis of different wood species.
4. Exploration of patterns and classification approaches.
